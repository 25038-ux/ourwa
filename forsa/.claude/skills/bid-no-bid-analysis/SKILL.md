# bid-no-bid-analysis

1. Policy (spec §14): FAIL (confirmed disqualifier) → NO-BID; UNKNOWN/CONFLICTING mandatory → REVIEW;
   GAP or NEEDS_HUMAN → BID WITH CONDITIONS; strong fit → BID. PLANNED items → REVIEW ("prepare").
2. Remediable gaps name the remediation (obtain, renew, partner, upload_evidence, add_financials…).
3. Economics are ranges with notes; never point estimates, never win probabilities.
4. The system recommends; `bid_decisions` records the human decision next to the system recommendation.
