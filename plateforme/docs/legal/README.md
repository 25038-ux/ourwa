# Le juridique

Les textes que les familles lisent vivent **à côté de l'application qui les
sert**, pas ici : `apps/web/content/legal/` — `confidentialite.{fr,ar}.md` et
`conditions.{fr,ar}.md`, rendus publiquement à `/legal/confidentialite` et
`/legal/conditions` (`?lang=ar` pour l'arabe). Les deux magasins exigent une URL
lisible sans compte ; c'est celle-là.

Ici : `declarations-magasins.md`, les réponses aux questionnaires « Sécurité
des données » (Play) et « Confidentialité de l'app » (App Store), dérivées du
code ligne par ligne, et la liste de ce que l'école doit fournir.

⚠ **Rien de tout cela n'a été relu par un juriste.** Les `[À COMPLÉTER]` sont
des faits sur l'école — raison sociale, adresse, hébergeur, durées légales de
conservation, autorité de contrôle — qu'un développeur ne doit pas inventer.
