PATRIMO — Suivi du patrimoine matériel
Mini-projet L1 Informatique : application web de gestion et de suivi
des matériels administratifs (PHP / MySQL / HTML5 / CSS3 / JavaScript).

------------------------------------------------------------------------
1. CONTENU
------------------------------------------------------------------------

  index.php            tableau de bord
  connexion.php        connexion / deconnexion.php
  materiels.php        liste, recherche et filtres
  materiel.php         fiche d'un matériel (état, transfert, historique)
  materiel_form.php    ajout / modification d'un matériel
  transferts.php       demandes de transfert et validation
  mouvements.php       historique complet + export CSV
  directions.php       gestion des directions        (admin)
  categories.php       gestion des catégories        (admin)
  utilisateurs.php     gestion des comptes           (admin)
  includes/            configuration, connexion BDD, fonctions, gabarits
  assets/              CSS, JavaScript, polices, icône
  sql/                 schema.sql (structure seule) et patrimo.sql
                       (structure + données de démonstration)
  tests/               parcours complet dans un navigateur (Playwright),
                       25 vérifications — à lancer sur une base de test

  Dans l'archive "patrimo_infinityfree.zip" :
    htdocs/            les fichiers à envoyer sur l'hébergeur
    base_de_donnees/   patrimo.sql et schema.sql à importer
    tests/             le script de test (inutile sur l'hébergeur)

------------------------------------------------------------------------
2. MISE EN LIGNE SUR INFINITYFREE
------------------------------------------------------------------------

  Les identifiants MySQL sont déjà renseignés dans
  htdocs/includes/config.php.

  a) Ouvrir le gestionnaire de fichiers (Online File Manager) du compte,
     entrer dans le dossier htdocs/ et supprimer le fichier par défaut
     "index2.html" s'il existe.

  b) Envoyer l'archive puis clic droit > Extract, ou envoyer par FTP
     (FileZilla : hôte ftpupload.net, port 21) : le CONTENU du dossier
     htdocs/ de l'archive doit se retrouver directement dans htdocs/
     de l'hébergement (index.php à la racine). Le fichier caché
     .htaccess doit être envoyé aussi.

  c) Ouvrir l'adresse du site : la page d'installation s'affiche.
     Cliquer sur "Installer Patrimo" : les tables et les données de
     démonstration sont créées. (Alternative : importer
     sql/patrimo.sql dans phpMyAdmin.) L'installation ne peut pas être
     relancée une fois la base remplie.

  d) Se connecter avec un compte de démonstration.

4. EN LOCAL (XAMPP / WAMP)
------------------------------------------------------------------------

  Copier le contenu de htdocs/ dans un dossier "patrimo" de htdocs
  (XAMPP) ou www (WAMP), créer une base "patrimo" dans phpMyAdmin,
  importer patrimo.sql, puis créer
  includes/config.local.php :

    <?php
    define('DB_HOST', 'localhost');
    define('DB_NAME', 'patrimo');
    define('DB_USER', 'root');
    define('DB_PASS', '');
    define('MODE_DEBUG', true);

  Ce fichier est prioritaire sur config.php et n'a pas besoin d'être
  envoyé sur l'hébergeur.

  Configuration minimale : PHP 7.4 ou plus (testé en PHP 8.4),
  MySQL 5.7+ ou MariaDB 10.3+.
